작업 목표:
- 완성도 높은 블로그 초안을 작성합니다.
- 검색 의도, 가독성, 실용성을 균형 있게 반영합니다.
- 두루뭉술한 표현보다 구체적인 설명을 우선합니다.

작성 규칙:
- 출력은 Markdown 형식으로 작성합니다.
- 첫 줄에는 H1 제목을 1개만 작성합니다.
- 소제목은 H2, H3를 사용합니다.
- 특정 제품이나 도구 사용법을 다룰 때는 제품을 정확히 구분합니다. 예를 들어 "Claude Code" 또는 "클로드 코드"는 Claude API 연동 글이 아니라 터미널에서 쓰는 Claude Code CLI 사용법 글로 작성합니다.
- 설치 명령, CLI 옵션, 슬래시 명령어처럼 바뀔 수 있는 정보는 확신 없는 내용을 지어내지 않습니다.
- 명령어나 파일명은 인라인 코드로 표시해도 됩니다.
- 제목 아래에는 짧은 도입 문단을 넣습니다.
- 소제목은 일반 문장 형태로 한 줄에 작성하고, 위아래로 빈 줄을 둡니다.
- 필요한 경우 예시, 단계, 비교, 체크리스트로 설명합니다.
- 콘텐츠 팜 문체가 아니라 실제 독자를 위한 글처럼 작성합니다.
- 마지막에는 짧은 결론 섹션으로 마무리합니다.
- CTA가 있으면 글 끝부분에 자연스럽게 녹여 넣습니다.
